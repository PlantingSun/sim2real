# 3. 图形界面说明

当前采用 Orin 本地显示器、键盘和鼠标，不需要再配置远程桌面。

## 当前连接

```text
Orin 全功能 Type-C ── USB-C 转 HDMI ── 显示器
Orin USB-A ── 键盘/鼠标
D435i USB3.2 Type-C ── Orin
```

这种方式直接使用 Orin 的 Ubuntu 桌面，适合运行 RealSense Viewer、相机查看程序和后续本地调试工具。显示器无信号时，先检查转换器、显示器输入源和端口标识，再用已验证的 RJ45 SSH 作为备用入口。

SSH 终端、X11 转发、VNC、NoMachine 和浏览器视频都暂不配置；它们不是读取 Orin 本地 D435i 的必要条件，也不应在没有需求时增加系统服务和网络变量。

## 安全边界

- 打开图形程序不会自动获得机器人运动控制权限。
- 相机查看阶段只读取 USB 相机，不发送 LowCmd 或 Sport Mode 指令。
- 任何准备长期运行或放到实机控制循环中的程序，都先在本项目中保留清晰注释并交由用户审查。
